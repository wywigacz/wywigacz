### [Bitcoin Barometer](https://github.com/wywigacz/bitcoin-barometer) · [live dashboard](https://wywigacz.github.io/bitcoin-barometer/)

An honest, self-testing Bitcoin price forecast: probabilistic price ranges for 7 to 180 days, 21 pre-registered
hypotheses, a 2-year holdout exam, prediction-market benchmarking and a virtual trader that explains every decision
in a [public journal](https://wywigacz.github.io/bitcoin-barometer/journal.html). Built on free public data and
refreshed every 6 hours by GitHub Actions.

`Python` · `pandas` · `scikit-learn` · `GARCH / HAR volatility models` · `walk-forward validation` · `GitHub Actions` · `GitHub Pages`
